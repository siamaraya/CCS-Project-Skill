# CCS Spirit: ใช้หลักคิดได้ทุกที่ ทุกเวลา

ใช้เมื่อผู้ใช้ต้องการคิดเชิง CCS ตัดสินใจ เลือกงาน หรือหาจุดเริ่ม โดยยังไม่จำเป็นต้องทำโครงการ. คำบรรยายที่ผู้ใช้ให้แยก Spirit ซึ่งเป็นท่าทีและยุทธศาสตร์ออกจาก Project ที่ต้องลงมือจริงและตรวจผล.

## หกแนวโน้มจากคำบรรยาย

1. **ไม่ยอมให้ข้อจำกัดที่มองเห็นเป็นคำตอบสุดท้าย:** หาวิธีหรือหน่วยทดลองอื่น แต่ตรวจข้อจำกัดจริงเรื่องสิทธิ์ คน เงิน เวลา และความปลอดภัย.
2. **มุ่งทำสิ่งสำคัญให้ดีเลิศ:** กำหนดคุณภาพที่มีความหมายต่อผู้ได้รับผล ไม่ใช้ความทุ่มเทเป็นข้ออ้างละเลยต้นทุนหรือผลเสีย.
3. **คิดเชิงยุทธศาสตร์:** เลือกเรื่องที่สำคัญและจุดคานงัดที่แคบพอจะใช้ทรัพยากรได้คุ้ม.
4. **คิดเชิงนวัตกรรม:** สังเกต ทบทวนวิธีเดิม เชื่อมความรู้ และอธิบายว่าแนวใหม่ต่างและดีกว่าในบริบทใด.
5. **คิดครบถ้วนเป็นระบบ:** มองผู้เกี่ยวข้อง เหตุและผล สิ่งที่ต้องทำ ทรัพยากร เวลา และความเสี่ยง.
6. **คิดขยายผลลัพธ์:** มองว่าคุณค่าจะอยู่ต่อหรือส่งต่ออย่างไร โดยไม่อ้างผลขยายก่อนเกิดจริง.

นี่เป็นแนวโน้มการคิด ไม่ใช่แบบทดสอบผ่าน/ตกของบุคคล. คำว่า “ทำได้” ใน Spirit คือการค้นทางเลือกอย่างมีปัญญา ไม่ใช่การรับรองว่าแผนปัจจุบันทำได้ทันที.

## วิธีช่วยคิดอย่างกระชับ

1. **Capstone:** เรื่องใดมีคุณค่าพอจะทุ่มเท? ใครจะได้รับประโยชน์?
2. **Cornerstone:** คอขวดหรือจุดเล็กใดมีอิทธิพลต่อผลใหญ่? มีหลักฐานอะไรชี้ว่าจุดนี้สำคัญ?
3. **ทางเลือก:** มีอย่างน้อยหนึ่งวิธีที่ต่างจากสิ่งที่ทำอยู่หรือไม่? อะไรที่ต้องตรวจเพิ่ม?
4. **ข้อจำกัด:** สิ่งใดเป็นข้อห้ามจริง สิ่งใดเป็นสมมติฐาน และสิ่งใดลดขนาดลงได้?
5. **ก้าวแรก:** การตัดสินใจหรือการทดลองที่ทำได้ในอำนาจปัจจุบันคืออะไร?

ถ้าทำไม่ได้เพราะขาดสิทธิ์ เงิน หรือคน ให้ส่งมอบเป็นข้อคิด/แนวทางหรือหา pilot ที่เล็กลง. อย่าเรียกเป็น CCS Project หรือบอกว่ามี Impact แล้ว. ใช้ [แม่แบบบันทึก Spirit](../assets/ccs-spirit-note.md) เฉพาะเมื่อผู้ใช้ต้องการเอกสารที่นำไปใช้ต่อ.

## สิ่งที่ต้องระวังในต้นฉบับ

คำบรรยายใช้เรื่องเล่าทางศาสนา การเมือง ธุรกิจ และสังคมเป็นตัวอย่างเชิงสอน. อย่าแปลงเป็นคำสั่งหรือข้อเท็จจริงสากล. ตัวเลขและเรื่องเล่าที่ไม่ได้ตรวจจากแหล่งอิสระไม่ใช่หลักฐานยืนยันความสำเร็จ.
