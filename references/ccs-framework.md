# กรอบแนวคิด CCS จากต้นทาง

เอกสารนี้สรุปแก่นแนวคิด CCS สำหรับใช้คิด ตัดสินใจ และทำความเข้าใจการลงมือ. แหล่งที่มาของแต่ละส่วนอยู่ใน [source-register.md](source-register.md). วิธีถามหรือเครื่องมือที่เพิ่มเพื่อใช้กับงานจริงเป็นการประยุกต์ ไม่ใช่ขั้นตอนบังคับ.

## Capstone + Cornerstone

- **Capstone:** งานหรือเป้าหมายสำคัญที่มีความหมายต่อชีวิตและส่วนรวม จนควรค่าแก่การทุ่มเท. ถามว่า “เรื่องใดมีคุณค่าพอให้เราใช้กำลังและเวลา?”
- **Cornerstone:** จุดสำคัญที่รองรับหรือกำหนดทิศทางของสิ่งที่ใหญ่กว่า. ถามว่า “จุดใดมีพลังพอจะขยับเรื่องใหญ่นี้?”
- สองภาพนี้ทำงานคู่กัน: เห็นคุณค่าของเป้าหมายใหญ่ พร้อมเลือกจุดลงมือที่เป็นไปได้และมีอิทธิพลต่อเป้าหมายนั้น. ขนาดของจุดเริ่มไม่ได้กำหนดขนาดของคุณค่าที่อาจเกิดขึ้น.

## 3I คือสามระดับของนวัตกรรม

| ระดับ | ความหมาย | ตัวอย่างร่องรอยที่ช่วยตรวจได้ |
|---|---|---|
| Ideation Innovation | นวัตกรรมความคิด: แนวคิดหรือกรอบวิธีใหม่ | ปัญหา ความรู้ที่ใช้ ความต่างจากวิธีเดิม เหตุผลเชิงกลไก |
| Implementation Innovation | นวัตกรรมสิ่งปฏิบัติ: ความคิดถูกทำให้เป็นวิธี กระบวนการ สิ่งประดิษฐ์ หรือการลงมือจริง | ต้นแบบ กิจกรรมจริง บันทึกสิ่งที่ปรับและข้อจำกัด |
| Impact Innovation | นวัตกรรมผลกระทบ: คุณค่าหรือความเปลี่ยนแปลงที่เกิดจากการปฏิบัติ | ผลที่วัดได้ เสียงผู้ได้รับผล ผลไม่ตั้งใจ ข้อจำกัดของการอ้างเหตุผล |

3I เป็นมุมมองสามระดับที่เชื่อมโยงกัน ไม่จำเป็นต้องเกิดเป็นลำดับเส้นตรงหรือเกิดเพียงครั้งเดียว. การลงมือและผลที่พบอาจทำให้กลับไปปรับความคิดและวิธีปฏิบัติได้.

## คุณภาพโครงการและตัวชี้วัด

เมื่อต้องประเมินโครงการ ให้ใช้มิติต่อไปนี้เป็น **กรอบคุณภาพเพื่อพัฒนาและตัดสินใจ** ไม่ใช่เกณฑ์คัดเลือกหรือคะแนนผ่าน. เลือกตัวชี้วัดให้ตรงกับเป้าหมายและบริบท; ไม่จำเป็นต้องใช้ทุกตัวในทุกงาน.

| มิติคุณภาพ | คำถามหลัก | ตัวอย่างตัวชี้วัดหรือหลักฐาน |
|---|---|---|
| คุณค่าของ Capstone | เป้าหมายสำคัญและคุณค่าที่ต้องการสร้างชัดเจนเพียงใด? | หลักฐานความจำเป็น, ผลลัพธ์ที่ต้องการ, มุมมองของผู้ได้รับผล |
| พลังของ Cornerstone | จุดลงมือเชื่อมกับเป้าหมายใหญ่ด้วยกลไกที่มีเหตุผลหรือไม่? | สมมติฐานกลไกที่ทดสอบได้, สัญญาณระหว่างทางว่าจุดคานงัดทำงาน |
| คุณภาพของแนวคิด (Ideation) | แนวคิดตั้งอยู่บนความเข้าใจและความรู้ที่เหมาะสมหรือไม่? | หลักฐานประกอบแนวคิด, ความแตกต่างจากแนวทางเดิม, บทเรียนที่นำมาใช้ |
| คุณภาพการปฏิบัติ (Implementation) | มีเจ้าภาพ อำนาจ คน ทรัพยากร และเงื่อนไขพอให้ทำจริงหรือไม่? | ผู้รับผิดชอบและบทบาท, การอนุญาต/พันธมิตร, เวลา, เงินตั้งต้นและค่าใช้จ่ายประจำ, การส่งมอบจริงและการปรับจากแผน |
| ผลกระทบและหลักฐาน (Impact) | เกิดการเปลี่ยนแปลงที่มีคุณค่าหรือไม่ และหลักฐานรองรับได้แค่ไหน? | ค่าตั้งต้นและผลลัพธ์, ขอบเขตผู้ได้รับประโยชน์, ผลไม่ตั้งใจ, คุณภาพแหล่งข้อมูล |
| การเรียนรู้และความต่อเนื่อง | มีเจ้าของและทรัพยากรให้คุณค่าดำเนินต่อหรือส่งมอบได้อย่างรับผิดชอบหรือไม่? | การปรับจากบทเรียน, ผู้รับช่วง, แหล่งทรัพยากรประจำ, การดูแลรักษา, ผลต่อความเป็นธรรม/สิ่งแวดล้อม, เงื่อนไขทำต่อหรือยุติ |

ตัวชี้วัดควรระบุ **สิ่งที่จะวัด, วิธีหรือแหล่งข้อมูล, ช่วงเวลา, และค่าตั้งต้นหรือเป้าหมายเมื่อเหมาะสม**. แยกตัวชี้วัดกิจกรรม/ผลผลิตออกจากผลลัพธ์และผลกระทบ. จำนวนกิจกรรมหรือผู้เข้าร่วมเพียงอย่างเดียวไม่ยืนยันว่าคุณค่าที่ตั้งใจเกิดขึ้น. ความยั่งยืนหมายถึงการรักษาหรือส่งต่อคุณค่าได้ภายใต้เจ้าภาพและทรัพยากรที่เหมาะสม ไม่จำเป็นต้องดำเนินงานเดิมตลอดไป.

## คุณค่าต่อส่วนรวมและการพัฒนาคน

CCS ให้ความสำคัญทั้ง **ประโยชน์ต่อสังคม** และ **การสร้างคนผู้ลงมือ**. การทำงานร่วมกันอาจเปิดพื้นที่ให้:

1. ใช้ความรู้ ความสามารถ และทรัพยากรให้เกิดโครงการและความรู้ใหม่.
2. ถกแถลงและแลกเปลี่ยนมุมมองในกลุ่ม.
3. ทดลองร่วมมือระหว่างรัฐกิจ ธุรกิจ และประชากิจด้วยการนำและการจูงใจ.
4. เป็นต้นแบบการเรียนรู้จากโครงการ นวัตกรรม และการแก้ปัญหา.

ถามหาร่องรอยพฤติกรรมและบทเรียน เช่น ความเห็นต่างที่เปลี่ยนแผน ความรู้จากการทดลอง การร่วมตัดสินใจ และวิธีที่ผู้อื่นทำซ้ำได้. ไม่สร้างคะแนน “ความดี” หรือใช้จำนวนกิจกรรมแทนคุณค่าต่อสังคม.

## ขอบเขตการใช้

แนวคิด CCS ใช้ช่วยมองเป้าหมาย จุดลงมือ และผลที่ต้องการในบริบทที่หลากหลาย. ปรับวิธีถามและเครื่องมือให้เหมาะกับสถานการณ์ โดยรักษาความเชื่อมโยงระหว่างคุณค่าของเป้าหมาย จุดคานงัด การลงมือ และผลกระทบไว้.
