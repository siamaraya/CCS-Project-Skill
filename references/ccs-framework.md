# กรอบแนวคิด CCS จากต้นทาง

เอกสารนี้ใช้เมื่อกำหนดนิยามหรือทบทวนโครงการ CCS. แหล่งที่มาของแต่ละส่วนอยู่ใน [source-register.md](source-register.md). คำถามตรวจในตารางเป็นการแปลงหลักการให้ทำงานได้ ไม่ใช่รูบริคทางการ.

## Capstone + Cornerstone

- **Capstone:** ผลงานสำคัญที่มีความหมายต่อชีวิตและส่วนรวม จนควรค่าแก่การจดจำ. ถามว่า “เรื่องใดคู่ควรกับกำลังและเวลาเรา?”
- **Cornerstone:** หินมุมเอกชิ้นเล็กซึ่งรับน้ำหนักหรือกำหนดทิศทางของโครงสร้างใหญ่. ถามว่า “จุดเล็กใด หากเปลี่ยนแล้วจะส่งผลต่อระบบ?”
- สองภาพนี้ต้องอยู่ด้วยกัน: เลือกเรื่องใหญ่ที่มีคุณค่า แล้วจับจุดแคบและคมพอจะเริ่มลงมือ. คำว่าเล็กไม่เท่ากับผลเล็ก และคำว่าผลกว้างไม่อนุญาตให้ตั้งเป้าลอย ๆ.

## เกณฑ์โครงการ 6 ข้อของ NBI

| เกณฑ์ | คำถามตรวจ | หลักฐานที่ควรมองหา |
|---|---|---|
| New Idea | วิธี กลไก หรือการผสมใหม่อย่างมีนัยสำคัญตรงไหน? | งานเดิมที่เกี่ยวข้อง ช่องว่าง และข้ออ้างความใหม่ที่พอดีกับหลักฐาน |
| Specific Issue | แก้ปัญหาใดเพียงเรื่องเดียว ใครพบ และที่ไหน? | ประโยคปัญหา ขอบเขต กลุ่มเป้าหมาย ข้อมูลสถานการณ์ |
| For the Commons | ส่วนรวมได้อะไร ใครได้ประโยชน์ และใครอาจเสียประโยชน์? | เสียงผู้ได้รับผล ประโยชน์ที่คาดและความเสี่ยง |
| Implementable | คน เงิน เวลา สิทธิ์ และพันธมิตรพอจะลงมือหรือไม่? | หน่วยงานรับผิดชอบ ทรัพยากร แผนและข้อจำกัด |
| Start Small | ทดลองที่เล็กที่สุดซึ่งยังทดสอบแก่นคิดได้อย่างไร? | ขนาดนำร่อง ระยะเวลา เหตุผลของขนาดและเกณฑ์เลือก |
| High Impact | ผลสำคัญที่คาดคืออะไร และผ่านกลไกใดจึงขยายได้? | ตัวชี้วัดผลที่มีความหมาย กลไกขยาย ผู้รับช่วง ต้นทุนและเงื่อนไข |

ใช้ผลทบทวนว่า **มีหลักฐาน / ยังไม่มีหลักฐาน / พบข้อขัดแย้ง** พร้อมระบุสิ่งที่ต้องแก้. อย่าตัดสินผ่านด้วยคะแนนที่ AI กำหนดเอง.

NBI ใช้เกณฑ์ New Idea ที่เข้มว่าแนวคิดใหม่และทะลุทะลวง ขณะที่สไลด์เยาวชนชวนต่อยอดจากวิธีเดิม. อ่านร่วมกันโดยให้ตรวจว่าเกิดสิ่งใหม่ในสาระสำคัญ ไม่ใช่เพียงเปลี่ยนชื่อหรือคัดลอก. ถ้าพบเพียง “ใหม่ในพื้นที่นี้” ให้ระบุระดับความใหม่และบอกว่า **ยังไม่ได้ยืนยันว่าตรงเกณฑ์ความใหม่ของต้นทางทั้งหมด**. อย่าอ้าง “ครั้งแรก” หากไม่มีการตรวจงานเดิมที่เพียงพอ.

## 3I คือสามระดับของนวัตกรรม

| ระดับ | ความหมาย | ตัวอย่างร่องรอยที่ช่วยตรวจได้ |
|---|---|---|
| Ideation Innovation | นวัตกรรมความคิด: แนวคิดหรือกรอบวิธีใหม่ | ปัญหา ความรู้ที่ใช้ ความต่างจากวิธีเดิม เหตุผลเชิงกลไก |
| Implementation Innovation | นวัตกรรมสิ่งปฏิบัติ: ความคิดถูกทำให้เป็นวิธี กระบวนการ สิ่งประดิษฐ์ หรือการลงมือจริง | ต้นแบบ กิจกรรมจริง บันทึกสิ่งที่ปรับและข้อจำกัด |
| Impact Innovation | นวัตกรรมผลกระทบ: คุณค่าหรือความเปลี่ยนแปลงที่เกิดจากการปฏิบัติ | ผลที่วัดได้ เสียงผู้ได้รับผล ผลไม่ตั้งใจ ข้อจำกัดของการอ้างเหตุผล |

ผู้เสนออธิบาย 3I เป็น **ระดับ** ของนวัตกรรม. สไลด์เยาวชนใช้ `Idea → Implementation → Impact` เป็นลำดับอธิบายที่เรียนรู้ได้ง่าย. ไม่ต้องบังคับว่าหนึ่งระดับเกิดได้ครั้งเดียวหรือห้ามย้อนกลับ. เมื่อนำร่องแล้วพบข้อผิดพลาด สามารถกลับไปแก้แนวคิด.

## ผลสองทางและเป้าหมายการเรียนรู้

CCS มุ่งทั้ง **ประโยชน์ต่อสังคม** และ **การสร้างคนผู้ลงมือ**. NBI อธิบายการเรียนรู้สี่ด้าน:

1. ใช้ความรู้ ความสามารถ และทรัพยากรให้เกิดโครงการและความรู้ใหม่.
2. ถกแถลงและแลกเปลี่ยนมุมมองในกลุ่ม.
3. ทดลองร่วมมือระหว่างรัฐกิจ ธุรกิจ และประชากิจด้วยการนำและการจูงใจ.
4. เป็นต้นแบบการเรียนรู้จากโครงการ นวัตกรรม และการแก้ปัญหา.

ถามหาร่องรอยพฤติกรรมและบทเรียน เช่น ความเห็นต่างที่เปลี่ยนแผน ความรู้จากการทดลอง การร่วมตัดสินใจ และวิธีที่ผู้อื่นทำซ้ำได้. ไม่สร้างคะแนน “ความดี” หรือใช้จำนวนกิจกรรมแทนคุณค่าต่อสังคม.

## ขอบเขตการใช้

คำสอนเรื่องอุดมการณ์ “สร้างคนเพื่อสร้างชาติ” เป็นฐานคุณค่าของต้นทาง. เมื่อใช้กับโจทย์ธุรกิจ องค์กร หรือชีวิตประจำวัน ให้ระบุว่าเป็นการประยุกต์ **CCS Spirit** หากยังไม่ได้ออกแบบงานเพื่อส่วนรวมตามเกณฑ์โครงการ. จำนวนสมาชิก ครูที่ปรึกษา และข้อกำหนดเวทีประกวดในเอกสารเก่าเป็นกติกาเฉพาะบริบท ไม่ใช่นิยาม CCS.
