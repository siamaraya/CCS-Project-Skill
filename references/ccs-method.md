# เชื่อม 3I จากความคิดสู่ผลกระทบ

ใช้หน้านี้เมื่อต้องการเชื่อมมุมมอง 3I เข้ากับการคิดและการลงมือ. 3I หมายถึงนวัตกรรมสามระดับ ไม่ใช่ขั้นตอนบังคับหรือกระบวนการเส้นตรง. ดูนิยามใน [ccs-framework.md](ccs-framework.md).

## Idea / Ideation

ทำความเข้าใจเรื่องที่ต้องการเปลี่ยนและคุณค่าที่ต้องการสร้าง. ใช้ความรู้และปัญญาพิจารณาความคิดหรือแนวทางที่อาจนำไปสู่การเปลี่ยนแปลง. อธิบายเหตุผลและกลไกที่คาดไว้ โดยแยกความคิดที่น่าสนใจออกจากผลที่พิสูจน์แล้ว.

## Implementation

พิจารณาว่าจะทำให้แนวคิดเกิดขึ้นจริงอย่างไร. หากต้องวางแผน อาจใช้คำถามต่อไปนี้เป็นจุดตั้งต้น:

| คำถาม | สิ่งที่ต้องระบุ |
|---|---|
| What | ต้องการให้เกิดอะไรที่สังเกตได้ |
| Who / Where | ช่วยใคร ในพื้นที่หรือระบบใด |
| How | ทำกิจกรรม/กระบวนการ/ต้นแบบอย่างไร |
| How much | ใช้ทรัพยากรเท่าไร จากใคร และมีเพดานเท่าไร |
| When | เริ่ม สิ้นสุด และตรวจผลเมื่อไร |

เติมผู้รับผิดชอบ ทรัพยากร สิทธิ์หรือการยินยอม ความเสี่ยง และบันทึกความต่างระหว่างแผนกับสิ่งที่ทำจริงตามความเหมาะสม. เป็นเครื่องมือประยุกต์ของ Skill.

## Impact

พิจารณาว่าเกิดการเปลี่ยนแปลงหรือคุณค่าใด และตรวจสอบได้อย่างไร. อธิบายว่าผลอาจต่อยอดไปสู่ส่วนที่ใหญ่ขึ้นได้ผ่านกลไกใด. แยกผลที่สังเกตแล้ว ผลที่คาด และผลที่ยังตรวจไม่ได้.

## นำไปใช้กับโจทย์ต่าง ๆ

- **คิด:** เป้าหมายสำคัญคืออะไร และจุดใดเป็น Cornerstone ที่เหมาะจะเริ่ม.
- **ทำ:** แนวคิดจะถูกนำไปปฏิบัติอย่างไร ภายใต้เงื่อนไขและทรัพยากรใด.
- **ดูผล:** อะไรเปลี่ยนแปลง เกิดคุณค่าแก่ใคร และมีหลักฐานอะไร.
- **เรียนรู้:** สิ่งที่พบทำให้ต้องปรับความคิดหรือการปฏิบัติอย่างไร.

เลือกใช้เฉพาะคำถามที่ช่วยโจทย์ตรงหน้า. หากต้องการวางแผนการปฏิบัติอย่างละเอียด ให้ใช้ [project-design.md](project-design.md) ประกอบ.
