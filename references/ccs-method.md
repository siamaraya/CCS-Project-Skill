# วิธีสอนและแปลง 3I ให้ลงมือ

สไลด์เยาวชน `180619_CCSP youth_edit.pptx` และไฟล์ข้อความประกอบเป็นฐานของคำอธิบายในหน้านี้. วิธีสอนนี้ช่วยให้ผู้เริ่มต้นเห็นเส้นทางจากความคิดสู่ผล แต่ไม่เปลี่ยนนิยามต้นทางว่า 3I คือ **นวัตกรรมสามระดับ**. ดูนิยามใน [ccs-framework.md](ccs-framework.md).

## Idea / Ideation

เริ่มจากมองเห็นปัญหา **เฉพาะเรื่อง** ที่มีผู้ได้รับผลจริง. ใช้ความรู้และปัญญาคิดวิธีที่ใหม่หรือพัฒนาจากสิ่งเดิม. ระบุว่าอะไรคือปัญหา ใครเป็นเจ้าของปัญหา วิธีเดิมทำอะไรได้/ไม่ได้ และแก่นความใหม่คืออะไร. ความคิดที่น่าสนใจยังไม่เท่ากับการพิสูจน์ผล.

## Implementation

นำแนวคิดลงไปทำจริง. แผนขั้นต่ำตอบห้าคำถามจากสไลด์:

| คำถาม | สิ่งที่ต้องระบุ |
|---|---|
| What | ต้องการให้เกิดอะไรที่สังเกตได้ |
| Who / Where | ช่วยใคร ในพื้นที่หรือระบบใด |
| How | ทำกิจกรรม/กระบวนการ/ต้นแบบอย่างไร |
| How much | ใช้ทรัพยากรเท่าไร จากใคร และมีเพดานเท่าไร |
| When | เริ่ม สิ้นสุด และตรวจผลเมื่อไร |

ในการใช้งานจริง ควรเติมผู้รับผิดชอบ สิทธิ์หรือการยินยอม ความเสี่ยง และบันทึกความต่างระหว่างแผนกับสิ่งที่ทำจริง. ส่วนที่เติมเป็นเครื่องมือประยุกต์ของ Skill.

## Impact

กำหนด **ตัวชี้วัดที่บอกคุณค่า** และตรวจว่าเกิดผลอะไรกับผู้ได้รับผล ไม่ใช่เพียงจำนวนกิจกรรม. อธิบายทางที่ผลจะขยายเกินจุดเริ่ม เช่น วิธีที่ส่งต่อได้ พันธมิตรรับช่วง หรือระบบที่ทำซ้ำได้. คำว่า “ผลกระทบสูง” ในแผนเป็นสมมติฐานจนกว่าจะมีหลักฐาน. แยกผลที่สังเกตแล้ว ผลที่คาด และผลที่ยังตรวจไม่ได้.

ตัวอย่างที่อยู่ในสไลด์ เช่น บันไดหรือโครงการขนาดใหญ่ ใช้เพื่อสอนเรื่องจุดเล็กกับผลกว้าง. ตัวเลขและสถานะโครงการในตัวอย่างเก่าไม่ใช่ข้อมูลปัจจุบันที่ใช้ซ้ำได้โดยไม่ตรวจ.

## รูปแบบคำตอบที่ช่วยผู้เรียน

- **คิด:** หนึ่งประโยคปัญหา + แนวคิดใหม่ + เหตุผลว่าจุดนี้เป็น Cornerstone.
- **ทำ:** What / Who-Where / How / How much / When และหน่วยนำร่องที่เล็กที่สุด.
- **ดูผล:** ตัวชี้วัด ค่าก่อนทำ วิธีตรวจผล เสียงผู้ได้รับผล และเงื่อนไขขยาย.
- **เรียนรู้:** อะไรเปลี่ยนในความเข้าใจและความสามารถของทีม; ต้องปรับอะไร.

หากผู้ใช้ขอเพียงคำอธิบายแนวคิด ให้ตอบตรงคำถาม ไม่บังคับกรอกทุกช่อง. หากขอทำโครงการ ให้ใช้ [project-design.md](project-design.md) ประกอบ.
