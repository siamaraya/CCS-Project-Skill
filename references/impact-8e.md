# 8E: เลนส์ยุทธศาสตร์เพื่อผลกว้างและยั่งยืน

บทความและคำบรรยายของผู้เสนอเชื่อม Impact Innovation กับ 8E. ใช้เมื่อออกแบบการขยายหรือทบทวนคุณค่าเชิงระบบ. 8E ไม่ใช่เช็กลิสต์ที่ pilot แรกต้องพิสูจน์ครบทุกข้อ. ดูที่มาใน [source-register.md](source-register.md).

| E | คำในต้นทาง | คำถามประยุกต์ |
|---|---|---|
| E1 | Efficiency — Input | ใช้คน เงิน และเวลาอย่างคุ้มค่าหรือไม่? |
| E2 | Excellence — Process | กระบวนการทำได้ดี เหมาะกับบริบท และรักษาคุณภาพหรือไม่? |
| E3 | Effectiveness — Output | ได้สิ่งที่ตั้งใจผลิตหรือทำตามเป้าและมาตรฐานหรือไม่? |
| E4 | Esteemed Valuableness — Outcome | ผลนั้นมีคุณค่าจริงต่อผู้คนหรือระบบหรือไม่? |
| E5 | Esthetic-Worthiness — Outdo | คุณค่าต่อส่วนรวมลึกกว่าผลเฉพาะหน้าอย่างไร? |
| E6 | Exponentiality — Outburst | คุณค่าเพิ่มทวีคูณผ่านคนหรือกลไกอื่นได้หรือไม่? |
| E7 | Externality — Outbound | ผลส่งไปยังกลุ่ม พื้นที่ หรือประเด็นนอกขอบเดิมได้หรือไม่? |
| E8 | Eschaton / Eschatonic Sustainability — Outlast | คุณค่ายังคงอยู่เมื่อเวลาผ่านไปหรือไม่? |

คำบรรยายใช้รูป **Eschatonicity** สำหรับ E8; บทความใช้รูปอังกฤษต่างกัน. ยึดสาระเรื่องผลที่อยู่ยาว ไม่สร้างนิยามใหม่จากความต่างของคำ. การจับคู่ Input/Process/Output/Outcome/... เป็นศัพท์เฉพาะของบทความ 8E; อย่านำไปปนกับศัพท์ประเมินโครงการทั่วไปโดยไม่บอกความหมาย.

วิธีใช้: ระบุ **เกิดแล้ว / มีสัญญาณ / ยังเป็นสมมติฐาน / ยังไม่เกี่ยว** สำหรับ E ที่เหมาะกับระยะงาน พร้อมหลักฐานหนึ่งประโยค. ใน pilot ให้เน้น E1–E4 ก่อน; E5–E8 เป็นคำถามเพื่อวางระบบส่งต่อและระยะยาว. ห้ามใช้คำว่า impact กว้างหรือยั่งยืนแทนข้อมูลจริง.
