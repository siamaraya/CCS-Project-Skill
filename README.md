# CCS Cap-Corner Stone

Agent Skill สำหรับช่วยคิด ออกแบบ ทบทวน และต่อยอดโครงการด้วยแนวทาง **Cap-Corner Stone (CCS)** โดยเน้นเลือกเป้าหมายที่มีคุณค่าต่อส่วนรวม แล้วหาจุดเริ่มต้นขนาดเล็กที่มีโอกาสสร้างผลกว้าง

> **ที่มาของแนวคิด:** แนวคิดและกรอบ CCS ที่เป็นฐานของ Skill นี้ตั้งต้นจากผลงานและคำสอนของ **ศาสตราจารย์ ดร. เกรียงศักดิ์ เจริญวงศ์ศักดิ์ (ดร.แดน)** เนื้อหาได้รับการสังเคราะห์จากเอกสารต้นทางและแหล่งอ้างอิงที่ระบุไว้ใน `references/source-register.md` ส่วนขั้นตอนการทำงาน เช็กลิสต์ และแม่แบบที่จัดทำเพิ่มเป็นการประยุกต์ของ Skill ไม่ใช่เอกสารทางการหรือสิ่งที่อ้างว่าท่านเขียนหรือรับรอง

## แก่นแนวคิด

CCS เชื่อม **Capstone** งานสำคัญที่มีคุณค่าควรค่าแก่การลงมือ เข้ากับ **Cornerstone** จุดเล็กแต่เป็นรากฐานหรือคานงัดที่ช่วยให้งานใหญ่นั้นเกิดขึ้นจริง หัวใจจึงไม่ใช่แค่ตั้งเป้าหมายให้ใหญ่ แต่คือการหา “จุดเริ่มที่ใช่” ซึ่งทำได้ภายใต้ข้อจำกัดและมีเหตุผลว่าจะสร้างประโยชน์ต่อส่วนรวมได้อย่างไร

เมื่อนำไปออกแบบโครงการ ให้พิจารณา 6 ด้าน ได้แก่ **แนวคิดใหม่ (New Idea), ปัญหาเฉพาะ (Specific Issue), ประโยชน์ต่อส่วนรวม (For the Commons), ความเป็นไปได้ในการลงมือ (Implementable), การเริ่มจากขนาดเล็ก (Start Small)** และ **โอกาสสร้างผลกระทบสูง (High Impact)** ใช้เป็นคำถามชวนตรวจ ไม่ใช่คะแนนตัดสินสำเร็จหรือล้มเหลว ส่วน 3I ช่วยมองนวัตกรรมในระดับความคิด การนำไปปฏิบัติ และผลกระทบที่เกิดขึ้นจริง

## ใช้งาน

`SKILL.md` คือคำสั่งหลักที่ AI Agent ใช้ ส่วน `references/` และ `assets/` เป็นเอกสารประกอบที่ Skill จะเลือกใช้ตามโจทย์

สำหรับ GitHub Copilot ใน VS Code ให้วางโฟลเดอร์ Skill นี้ไว้ที่:

```text
.github/skills/ccs-cap-corner-stone/
```

คง `SKILL.md`, `references/` และ `assets/` ไว้ด้วยกัน เพื่อให้ลิงก์เอกสารประกอบทำงานครบ จากนั้นถามเป็นภาษาธรรมชาติ หรือระบุ Skill โดยตรง เช่น:

```text
ใช้ $ccs-cap-corner-stone ตรวจโครงการนี้จากหลักฐานที่มี แล้วเสนอแผนทดลองรอบถัดไป
```

## ใช้กับงานแบบไหน

- **คิดและตัดสินใจ:** หา Capstone ที่ควรทำ, Cornerstone ที่ควรเริ่ม และการลงมือขั้นถัดไปที่เป็นไปได้
- **ออกแบบโครงการ:** ระบุปัญหา ผู้ได้รับผล แนวคิดใหม่ ขนาดนำร่อง หลักฐาน และทางสร้างคุณค่าสาธารณะ
- **ทบทวนโครงการ:** ตรวจช่องว่างสำคัญ เชื่อมข้อค้นพบกับหลักฐาน และวางแผนรอบถัดไป
- **ประเมินผลและขยายผล:** กำหนดค่าตั้งต้น ตัวชี้วัด บันทึกผลจริง ผลไม่ตั้งใจ และเงื่อนไขว่าจะทำต่อ ปรับ ทดลองซ้ำ หรือหยุด

## เอกสารประกอบ

Skill จะอ่านเฉพาะส่วนที่เกี่ยวข้องกับโจทย์:

- `references/ccs-spirit.md` สำหรับการคิดเชิงยุทธศาสตร์และการตัดสินใจ
- `references/ccs-framework.md`, `references/ccs-method.md` และ `references/project-design.md` สำหรับหลักการและการออกแบบโครงการ
- `references/project-audit-and-iteration.md` สำหรับการตรวจและพัฒนาโครงการที่กำลังดำเนินอยู่
- `references/impact-measurement.md` และ `references/impact-8e.md` สำหรับการวัดผลและการขยายคุณค่า
- `references/source-register.md` สำหรับที่มาและขอบเขตของข้ออ้าง
- `assets/` มีแม่แบบสำหรับบันทึก Spirit, canvas, รายงานทบทวน, หลักฐานและการตัดสินใจ, แผนรอบถัดไป และการเรียนรู้จากการนำร่อง

## หลักการสำคัญ

- ใช้เกณฑ์โครงการ CCS 6 ข้อเป็นคำถามตรวจ ไม่สร้างคะแนนหรือเกณฑ์ผ่านขึ้นเอง
- แยกหลักการจากแหล่งอ้างอิง หลักฐานของโครงการ และเครื่องมือที่ Skill เสนอ
- ไม่แต่งข้อมูลผู้ได้รับผล งบประมาณ การอนุญาต ค่าตั้งต้น หรือผลลัพธ์ที่ยังไม่มีหลักฐาน
- แยกผลที่เกิดขึ้นแล้วออกจากผลที่คาดหวัง และบอกข้อจำกัดของหลักฐาน
- ไม่ถือว่าการเริ่มเล็ก การเข้าถึงคนจำนวนมาก หรือการประชาสัมพันธ์ เป็นหลักฐานของผลกระทบโดยลำพัง
