# CCS one-page canvas

> แม่แบบประยุกต์ของ Skill ไม่ใช่แบบฟอร์มทางการของผู้เสนอ CCS

**ชื่อแนวคิดและเจ้าของงาน:**

**Capstone:** คุณค่าต่อส่วนรวมที่ทำให้เรื่องนี้คู่ควร

**Cornerstone:** จุดเล็กที่น่าจะเปลี่ยนภาพใหญ่ และเหตุผลที่เลือกจุดนี้

**ปัญหาหนึ่งประโยค:** กลุ่มใด / อยู่ที่ไหน / ประสบอะไร / มีหลักฐานอะไร

**เสียงผู้ได้รับผล:** ใครได้พูดแล้ว ใครยังไม่ถูกฟัง

**ความรู้เดิมและความใหม่:** วิธีที่มีอยู่ / ช่องว่าง / กลไกใหม่ / ระดับความใหม่ที่ตรวจยืนยันได้

**pilot เล็กที่สุด:** What / Who-Where / How / How much / When

**ความพร้อมลงมือ:** เจ้าภาพและอำนาจ / คนและทักษะ / งบเริ่มต้นและค่าใช้จ่ายประจำ / พันธมิตรและการอนุญาต / ความเสี่ยงและแผนสำรอง

**ผลที่จะตรวจ:** ตัวชี้วัดหลัก / ค่าเริ่มต้น / วิธีเก็บ / ผลเสียที่ต้องเฝ้า

**ความยั่งยืน:** ผู้ดูแลต่อ / แหล่งทรัพยากร / การบำรุงรักษา / เงื่อนไขทำต่อหรือยุติ

**ทางต่อยอด:** ทำให้ดีขึ้น / ทดลองซ้ำ / ร่วมมือ / ผนวกกับระบบเดิม / ขยาย พร้อมเงื่อนไขและความเสี่ยง

**กรณีจริงที่ใกล้เคียง:** โครงการและแหล่งอ้างอิง / จุดที่คล้ายและต่าง / บทเรียนที่นำมาทดลองได้

**การเรียนรู้:** สิ่งที่ทีมและผู้เกี่ยวข้องค้นพบ / สิ่งที่ควรปรับ / เงื่อนไขการต่อยอด
