# รายงานตรวจและต่อยอดโครงการ CCS

> แม่แบบประยุกต์ของ Skill; สถานะและลำดับความสำคัญเป็นเครื่องมือทบทวนภายใน ไม่ใช่ขั้นตอนทางการของ CCS

**โครงการ / รอบตรวจ / วันที่ / ผู้ตรวจ:**

**แผนหรือข้อมูลรุ่นที่ตรวจ:** ชื่อไฟล์/ลิงก์ เวอร์ชัน ช่วงเวลาข้อมูล

**จุดคานงัดที่เลือก (Cornerstone):**

**ข้อค้นพบที่กระทบผลมากที่สุด:**

## ประเมินคุณภาพโครงการตามกรอบ CCS

เลือกมิติและตัวชี้วัดที่เกี่ยวข้องกับโครงการ. สถานะ: **มีหลักฐานรองรับ / ยังไม่มีหลักฐานพอ / ขัดกับหลักฐาน / ยังไม่เกี่ยวในระยะนี้**. ระบุที่มาหรือรหัสหลักฐานในทุกแถวที่มีข้อสรุป.

| มิติคุณภาพ | ตัวชี้วัด/เป้าหมาย | สถานะ | หลักฐาน/ที่มา | ช่องว่างและผลกระทบ | การแก้ที่แนะนำ |
