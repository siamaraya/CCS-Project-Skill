# บันทึก pilot และการเรียนรู้ CCS

> แม่แบบประยุกต์ของ Skill แยกสิ่งที่ทำจริง ผลที่ตรวจได้ และข้อคาดการณ์

**โครงการ / รอบทดลอง / วันที่ / ผู้บันทึก:**

## ก่อนทดลอง

**สมมติฐานและกลไก:**

**ขอบเขต:** What / Who-Where / How / How much / When

**สิทธิ์และความยินยอมที่จำเป็น:**

**ตัวชี้วัดหลัก:** นิยาม หน่วย สูตร ค่าเริ่มต้น เป้าหมาย วิธีเก็บ เจ้าของข้อมูล

**ผลเสียที่ต้องเฝ้าและเกณฑ์หยุด:**

## ระหว่างทดลอง

| วันที่ | สิ่งที่ทำจริง | ต่างจากแผน/เหตุผล | ทรัพยากรจริง | ข้อสังเกตและหลักฐาน |
|---|---|---|---|---|

**การเรียนรู้ของทีม:** ความรู้ใหม่ / ความเห็นต่างที่เปลี่ยนแผน / ความร่วมมือ / วิธีที่ถ่ายทอดได้

**คำตัดสิน:** ทำต่อ / ปรับ / ทดสอบซ้ำ / หยุด พร้อมหลักฐานและสิ่งที่ต้องทำถัดไป
