# บันทึกตัดสินใจด้วย CCS Spirit

> แม่แบบประยุกต์ของ Skill สำหรับคิดและลงมือขั้นแรก ยังไม่ใช่ CCS Project หรือหลักฐานว่าเกิด Impact

**เรื่องที่กำลังตัดสินใจ:**

**Capstone — ทำไมเรื่องนี้คู่ควร:** ใครจะได้ประโยชน์ และคุณค่าที่ต้องการสร้างคืออะไร?

**Cornerstone — จุดเล็กที่มีแรงคานงัด:** ปัญหาหรือคอขวดเฉพาะคืออะไร? รู้ได้อย่างไรว่าสำคัญ?

**วิธีเดิมและทางเลือกใหม่:** มีใครทำอะไรแล้ว? เราเสนอความต่างอะไร และยังต้องตรวจอะไร?

**ข้อจำกัด:** อะไรเป็นข้อเท็จจริง อะไรเป็นสมมติฐาน? มีสิทธิ์ คน เวลา และทรัพยากรพอสำหรับขั้นใด?

**ก้าวแรกที่ทำได้ตอนนี้:** ผู้รับผิดชอบ / เมื่อไร / สิ่งที่จะสังเกต

**หากอยากพัฒนาเป็น CCS Project:** ปัญหาเฉพาะ ผู้ได้รับผล pilot หลักฐาน และทางขยายใดที่ยังขาด?
